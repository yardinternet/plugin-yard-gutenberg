# Icon list block

## Usage in Blade

```blade
<x-block-yard-iconlist class="is-style-borders">
    <x-block-yard-iconlist-item icon="fa-light fa-arrow-right" listText="Item text" linkUrl="/page" />
    <x-block-yard-iconlist-item icon="fa-light fa-check" listText="Item without link" />
</x-block-yard-iconlist>
```

### Attributes

No block attributes are used when rendering. The `class` attribute is passed through, e.g. for a block style.
