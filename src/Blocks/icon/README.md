# Icon block

## Usage in Blade

```blade
<x-block-yard-icon icon="fa-light fa-envelope" iconAltText="E-mail" />
```

### Attributes

| Attribute     | Type     | Description                                                              |
| ------------- | -------- | ------------------------------------------------------------------------ |
| `icon`        | `string` | Font Awesome classes. Default `fa-classic fa-light fa-envelope`.         |
| `iconAltText` | `string` | `title` attribute of the icon. The icon itself is `aria-hidden`.         |
