# Slide block

## Usage in Blade

```blade
<x-block-yard-slider>
    <x-block-yard-slide>
        <p>Slide content</p>
    </x-block-yard-slide>
</x-block-yard-slider>
```

### Attributes

No block attributes are used when rendering. See the [slider README](../slider/README.md) for the SplideJS setup.
